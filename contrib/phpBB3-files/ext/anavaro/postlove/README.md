Post Love for phpBB 3.2, when installed on webDiplomacy.net
==========

NOTE: This vendored copy is the canonical version for webDiplomacy and is AHEAD of
the github.com/kestasjk/postlove fork (it has fixes for ajax profile links and
hiding like info from anonymous users that were only committed here). It is
deployed onto the phpBB install by gitpull.php along with the rest of
contrib/phpBB3-files; do not overwrite it from the fork.

Description:

    Add +1 to people's posts.
	Targeted at those using webDip with phpBB3; see the original extension if installing on a vanilla phpBB3 version (this version will still work, but the tweaks have no point on a vanilla install)
